Deal Beacon is a Black Friday and Cyber Monday deal finder: a static site listing 60 real deals our agent found and re-checked on Nov 28, 2026 at their stores, each with its product, store, sale price, usual price, discount, a link to the product at the store, when its price was checked, where it was read, and an honest verdict on whether it is really a deal (new low, strong deal, routine sale, or inflated). Search and filters by category, store, discount and verdict, sorting by biggest discount, best verdict, lowest price or newest check, and 12 same-product comparisons across stores. It runs entirely from its own files — no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.

## Hand in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
